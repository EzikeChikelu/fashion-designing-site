# Tickerboard

A single-file crypto price dashboard. No build step, no dependencies.

- Live prices from the free CoinGecko API, refreshed every 30 seconds
- Inline SVG sparklines (7 days), 1h / 24h / 7d change pills
- Watchlist, price alerts, USD / NGN / EUR switching (saved in the browser)
- Falls back to clearly labelled demo data if CoinGecko can't be reached

Open `index.html` in a browser, or serve the repo with GitHub Pages and visit `/tickerboard/`.
